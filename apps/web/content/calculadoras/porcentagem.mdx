# Calculadora de Porcentagem Online

A porcentagem é uma das ferramentas matemáticas mais usadas no cotidiano — de descontos em
compras a análise de rendimentos financeiros. Esta calculadora resolve os 6 tipos mais comuns
de cálculo percentual.

## Os 6 tipos de cálculo de porcentagem

### 1. Calcular X% de um valor

**Pergunta:** Quanto é 15% de R$ 2.400?

```
Resultado = Valor × (Percentual ÷ 100)
Resultado = 2.400 × 0,15 = R$ 360
```

### 2. Que percentual X representa de Y?

**Pergunta:** R$ 360 é que percentual de R$ 2.400?

```
Percentual = (Parte ÷ Total) × 100
Percentual = (360 ÷ 2.400) × 100 = 15%
```

### 3. Se X é Y% de que valor?

**Pergunta:** R$ 360 é 15% de qual valor?

```
Total = Parte ÷ (Percentual ÷ 100)
Total = 360 ÷ 0,15 = R$ 2.400
```

### 4. Variação percentual (aumento ou queda)

**Pergunta:** O preço foi de R$ 80 para R$ 92 — qual foi o aumento?

```
Variação = [(Valor final − Valor inicial) ÷ Valor inicial] × 100
Variação = [(92 − 80) ÷ 80] × 100 = 15%
```

Se o resultado for negativo, indica queda.

### 5. Acréscimo percentual (adicionar %)

**Pergunta:** Preço de R$ 500 com 8% de acréscimo:

```
Valor final = Valor inicial × (1 + Percentual ÷ 100)
Valor final = 500 × 1,08 = R$ 540
```

### 6. Desconto percentual (subtrair %)

**Pergunta:** Preço de R$ 500 com 12% de desconto:

```
Valor final = Valor inicial × (1 − Percentual ÷ 100)
Valor final = 500 × 0,88 = R$ 440
```

## Porcentagem no dia a dia

### Desconto em compras

Ao ver "30% OFF" em uma promoção:

```
Desconto = Preço original × 0,30
Preço final = Preço original × 0,70
```

**Atenção:** descontos sucessivos não se somam diretamente. "20% + 10% de desconto" não é
30% — é: 1 − (0,80 × 0,90) = 28% de desconto total.

### Gorjeta em restaurante

Gorjeta de 10% sobre uma conta de R$ 180:

```
Gorjeta = 180 × 0,10 = R$ 18
Total = R$ 198
```

### Reajuste salarial

Salário de R$ 3.000 com reajuste de 6%:

```
Novo salário = 3.000 × 1,06 = R$ 3.180
Aumento nominal = R$ 180
```

## Markup vs. margem: a confusão mais comum

**Margem de lucro** é calculada sobre o preço de venda:

```
Margem = [(Preço de venda − Custo) ÷ Preço de venda] × 100
```

**Markup** é calculado sobre o custo:

```
Markup = [(Preço de venda − Custo) ÷ Custo] × 100
```

**Exemplo:** custo R$ 100, preço de venda R$ 150

```
Margem = [(150 − 100) ÷ 150] × 100 = 33,3%
Markup = [(150 − 100) ÷ 100] × 100 = 50%
```

O markup é sempre **maior** que a margem para o mesmo produto — porque usa o custo (menor)
como base. Nunca confundir os dois conceitos ao precificar!

## Porcentagem em investimentos

### Rentabilidade de um CDB

CDB que foi de R$ 10.000 para R$ 10.820 em 1 ano:

```
Rentabilidade = [(10.820 − 10.000) ÷ 10.000] × 100 = 8,2% a.a.
```

### Comparar fundos

Fundo A: +12% ao ano / Fundo B: +1% ao mês

```
Fundo B anualizado = (1,01)^12 − 1 = 12,68% ao ano
```

Fundo B é melhor — e isso não seria óbvio sem converter para a mesma base.

## Porcentagem em questões de concursos e ENEM

Tipo mais recorrente: **"Uma loja aumentou o preço em X% e depois deu desconto de Y%.
O preço final é maior ou menor que o original?"**

Solução: aplicar os multiplicadores em sequência.

**Exemplo:** aumentou 20% e depois deu 20% de desconto:

```
Multiplicador final = 1,20 × 0,80 = 0,96 → preço final é 4% MENOR
```

Aumentos e descontos iguais sempre resultam em valor menor — porque o desconto incide
sobre um valor maior.

## Perguntas frequentes sobre porcentagem

**Qual a diferença entre ponto percentual e porcentagem?**

"Ponto percentual" (p.p.) é a diferença aritmética entre dois percentuais. Se a taxa de
juros foi de 10% para 12%, aumentou 2 pontos percentuais (mas 20% em termos relativos).
Confundir os dois é um erro frequente em notícias econômicas.

**Como calcular porcentagem de porcentagem?**

Multiplique as taxas em forma decimal. 15% de 20% = 0,15 × 0,20 = 0,03 = 3%.

**Como calcular desconto regressivo (reverso)?**

Se o preço com 15% de desconto é R$ 850, o preço original era:

```
Original = 850 ÷ (1 − 0,15) = 850 ÷ 0,85 = R$ 1.000
```

Não some o percentual de volta — use a divisão pelo complemento.

**O que é percentil?**

Percentil é diferente de porcentagem. Percentil 75 significa que 75% dos valores de uma
distribuição estão abaixo desse ponto — é uma medida de posição estatística, não uma
proporção direta.

**Como calcular inflação acumulada?**

Inflação acumulada não é soma, é multiplicação:

```
Acumulado = (1 + inf_1) × (1 + inf_2) × ... × (1 + inf_n) − 1
```

Inflação de 5% e depois 4% = 1,05 × 1,04 − 1 = 9,2% (não 9%).
